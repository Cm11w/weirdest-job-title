## The entry

> **Night-Shift Lullaby Singer for Insomniac ATMs**

A single job title — 45 characters, one line, nothing else. The bet: a
completely ordinary night-shift job (a lullaby singer) with one gloriously
specific twist (the audience is ATMs that cannot sleep). It reads like a
real posting HR might have approved, until the last two words.

## How it works

`main.ts` (Node 22) writes exactly that one title to `/output/entry.txt`,
after checking it against the competition gate itself: 1–60 characters, a
single non-blank line.

```sh
node main.ts
cat /output/entry.txt
```
